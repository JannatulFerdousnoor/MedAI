# MedAI - Intelligent Healthcare Assistant 🏥

**MedAI** একটি ওয়েব-ভিত্তিক প্ল্যাটফর্ম যা কৃত্রিম বুদ্ধিমত্তা ব্যবহার করে স্বাস্থ্যসেবা সংক্রান্ত বিভিন্ন তথ্য এবং সহায়তা প্রদান করে। এটি ব্যবহারকারীদের প্রাথমিক লক্ষণের ভিত্তিতে সম্ভাব্য রোগ নির্ণয় এবং প্রয়োজনীয় পরামর্শ দিতে সক্ষম।

## ✨ বৈশিষ্ট্যসমূহ (Features)
- **AI Health Assistance:** ব্যবহারকারীর লক্ষণের উপর ভিত্তি করে তাৎক্ষণিক পরামর্শ।
- **Assignment Tracking:** স্বাস্থ্য সংক্রান্ত তথ্য বা কাজগুলো ট্র্যাক করার সুবিধা।
- **User-Friendly UI:** খুব সহজ এবং সুন্দর ইন্টারফেস যা সবার জন্য ব্যবহার উপযোগী।
- **Responsive Design:** মোবাইল এবং কম্পিউটার—উভয় ডিভাইসেই অনায়াসে ব্যবহার করা যায়।

## 🛠 প্রযুক্তি (Technologies Used)
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (Functional Application)
- **Database:** MySQL (Storage Management)
- **Tools:** Git, GitHub, VS Code
